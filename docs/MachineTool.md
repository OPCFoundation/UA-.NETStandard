# Machine Tools and Wireless Peripherals

| Feature | Support |
| --- | --- |
| OPC 40501-1 MachineTool 1.02.0 and OPC 40505 WMTP 1.0.0 | Supported; WMTP is bundled, with its own namespace and independent WMTP-only hosting |
| Machine monitoring, channels, working units, tools/life, prognoses and conditions | Supported through explicit providers |
| Retained Production, states/parts/statistics, Machinery/ISA95 jobs and remote files | Supported |
| WMTP's eight measurement kinds, checked trigger/delta settings and acquired quality/time | Supported |
| WMTP battery/service metadata, calibration mode and UTC/time-zone requests | Supported with selected providers |
| Independent work/service records: count, complete reports, ranges, delete and explicit abort | Supported; reads do not consume records or silently truncate |
| Firmware/licence byte transfer | Supported as authorized provider acceptance, not installation/activation |
| Shared/standalone hosting, isolated instances, typed clients, bounded MCP and NativeAOT | Supported |
| Separate WMTP package/profile, CNC execution, Bluetooth/pairing, flash/licensing or safety drivers | Not supported |
| External OPC Foundation certification of a deployment | Not claimed |
