# Cranes and Hoists

| Feature | Support |
| --- | --- |
| Released OPC 40020-1 1.00 model and provider-backed runtime | Supported |
| Controllers, motion devices, axes, motors, brakes, loads and protective functions | Supported |
| Raw values, quality/timestamps, geometry and equipment references | Supported |
| Standard speed-limit setpoint/enable requests | Supported with explicit provider authorization; acceptance is not active hardware state |
| Standalone/shared Machinery-Robotics hosting and isolated instances | Supported |
| Typed clients, bounded MCP tools, samples and NativeAOT | Supported |
| Model/server/client/MCP packages, including Debug variants | Preview only |
| Physical motion control or safety-system implementation | Not supported |
| External OPC Foundation certification of a deployment | Not claimed |
