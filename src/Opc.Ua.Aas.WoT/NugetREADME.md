# OPC UA .NET Standard — Asset Administration Shell Web of Things bridge

`OPCFoundation.NetStandard.Opc.Ua.Aas.WoT` is the Annex F bridge package for mapping W3C
Thing Descriptions into the OPC UA for Asset Administration Shell V3 AddressSpace projection.

## Overview

Reference this package when composing AAS V3 projection code with the Web of Things converter
surface from `Opc.Ua.Types`. The package is intentionally scaffolded as the home for the AAS
and WoT bridge; implementation code is added in the companion bridge feature work.

## Target frameworks

`net472`, `net48`, `netstandard2.1`, `net8.0`, `net9.0`,
`net10.0`.
