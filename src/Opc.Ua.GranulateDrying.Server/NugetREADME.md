# OPC UA Granulate Drying Server

Provider-backed server support based on OPC 40082-6 version 1.0.0.

- Real generated `GranulateDryingDeviceType`, bin, bed, maintenance, and user instances.
- Standalone hosting or composition under one existing DI/Machinery owner, with AMB-compatible assets.
- Independently selected optional controls and measurements, not an all-features-only sample.
- Authorized asynchronous providers, per-device control ownership, observers, and absolute committed values.
- Reused common parameter/configuration/controller binders, retained alarms, and standard read-only FileType documents.

Equipment behavior, persistence, and simulation belong to injected application providers.
This package does not claim OPC Foundation/EUROMAP certification.

See [Granulate drying documentation](https://github.com/OPCFoundation/UA-.NETStandard/blob/master/docs/GranulateDrying.md)
for the complete capability matrix, provider contract, provenance, and examples.
