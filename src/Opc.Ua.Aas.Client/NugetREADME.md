# OPC UA .NET Standard — Asset Administration Shell client

`OPCFoundation.NetStandard.Opc.Ua.Aas.Client` is the client-side helper library for the
OPC UA for Asset Administration Shell V3 companion model and its xRegistry-based registry
surface.

## Overview

Reference this package alongside `Opc.Ua.Client` from tools that browse AAS AddressSpaces or
manage an AAS registry on an OPC UA server. The package is intentionally scaffolded as the home
for AAS client helpers and xRegistry-derived registry clients; implementation code is added in
the companion client feature work.

## Target frameworks

`net472`, `net48`, `netstandard2.1`, `net8.0`, `net9.0`,
`net10.0`.
