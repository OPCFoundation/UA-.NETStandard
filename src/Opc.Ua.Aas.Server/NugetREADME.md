# OPC UA .NET Standard — Asset Administration Shell server

`OPCFoundation.NetStandard.Opc.Ua.Aas.Server` is the server-side helper library for the
OPC UA for Asset Administration Shell V3 companion model and its xRegistry-based registry
surface.

## Overview

Reference this package from a custom OPC UA server that needs to host the AAS V3 AddressSpace
projection or the AAS registry. The package is intentionally scaffolded as the home for the
server node managers and xRegistry-derived projection runtime; implementation code is added in
the companion server feature work.

## Target frameworks

`net472`, `net48`, `netstandard2.1`, `net8.0`, `net9.0`,
`net10.0`.
