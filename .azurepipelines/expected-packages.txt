# `dotnet pack preview-pack.slnx`, one package id per line.

# `validate-source-generator-packages.ps1` fails the build when the packed output
# does not match this list exactly. The point is that adding, removing or renaming
# a shipped package has to be a conscious, reviewed act - a package silently
# disappearing (or a private build-time project accidentally becoming packable)
# is otherwise invisible until consumers notice.
#
# Lines starting with '#' and blank lines are ignored. The list covers the modern
# `dotnet pack` output only; the hand-authored `nuget/*.nuspec` packages are packed
# in a later pipeline step and are not part of this check.
#
# To update: run `dotnet pack preview-pack.slnx` and reconcile the produced
# package ids with this file in the same pull request that changes them.
